---
name: Repeat sequence entry
description: User's expected workflow for finishing several sequences for the same trips.
---

The user wants to click “New Sequence,” automatically save the sequence just completed, keep the same trip, and only enter the name, city, and pasted sequence again.

**Why:** The user was having to refresh the browser to start another sequence and then re-enter the dates and times.

**How to apply:** Preserve this repeat-entry workflow when changing the sequence finisher. Starting another sequence must not require a browser refresh or repeated trip setup.
